Advanced Features

NEO is designed for sophisticated AI interactions with advanced capabilities.

Multi-Model Orchestration

Intelligently routes tasks between conversational (smollm2) and analytical (deepseek-r1) models based on context and requirements.

Persistent Memory System

Maintains comprehensive session memory with categorized storage (MOOD, GOAL, NOTE, FEEDBACK, REFLECTION) across interactions.

Context-Aware Routing

Automatically selects the optimal AI model based on task type, complexity, and user preferences for maximum effectiveness.

Continuous Learning

Implements reflection mechanisms that allow the system to learn from interactions and improve responses over time.

Cross-Platform Synchronization

Maintains environment consistency across multiple development machines with seamless synchronization capabilities.

Personalized Experience

Adapts to user preferences, interaction patterns, and specific use cases for a truly customized AI assistant.

Advanced Setup

Get NEO AI Console running on your Windows system with these steps.

1

Install Ollama

First, install Ollama on your Windows system to manage AI models.

# Download Ollama for Windows
# Visit https://ollama.ai/download
2

Download NEO Script

Download the NEO AI Console batch script to your preferred directory.

# Download NEO batch script
curl -o neo-console.bat https://neo.ai/download/neo-console.bat
3

Configure Models

Pull the required AI models using Ollama.

# Pull conversation model
ollama pull smollm2

# Pull analytical model
ollama pull deepseek-r1
4

Run NEO

Execute the batch script to start the NEO console with all advanced features.

# Run NEO console
neo-console.bat
